# Project Structure

This project uses a module-based folder structure adapted for TanStack Router's file-based routing.

## Overview

```
src/
├── app/
│   ├── index.tsx          # Entry point — mounts the React app
│   ├── router/            # All routing infrastructure
│   │   ├── index.ts       # Router factory (createRouter / getRouter)
│   │   ├── routeTree.gen.ts  # Auto-generated by TanStack Router — never edit
│   │   └── routes/        # File-based route components
│   │       ├── __root.tsx
│   │       ├── index.tsx
│   │       ├── about.tsx
│   │       ├── blog.index.tsx
│   │       └── blog.$slug.tsx
│   └── styles/
│       └── styles.css     # Global Tailwind styles
├── modules/               # Self-contained business modules
├── shared/                # Cross-cutting utilities and infrastructure
│   ├── api/               # API clients and DTOs
│   ├── hooks/             # Shared React hooks
│   ├── lib/               # Third-party configs and utilities
│   ├── queries/           # React Query queries and mutations
│   └── ui/                # Shared UI components
│       ├── widgets/       # Composed UI blocks (Header, Footer)
│       ├── app/           # App-aware shared UI
│       └── primitives/    # Generic primitive UI components
└── domain/                # Business rules and validators
```

## Naming Conventions

- File and module paths use lowercase kebab-case: `theme-toggle.tsx`, `error-boundary.tsx`
- React component symbols use PascalCase: `ThemeToggle`, `ErrorBoundary`
- Directory names use lowercase kebab-case: `error-display/`, `game-settings/`

## Layers

### `app/`

Application bootstrap. `app/index.tsx` is the sole entry point — it creates the router and mounts React. Everything else in `app/` is a subfolder.

#### `app/router/`

All routing infrastructure lives here.

- `index.ts` — exports `getRouter()`, the router factory used by the entry point
- `routeTree.gen.ts` — auto-generated by the TanStack Router Vite plugin; never edit manually
- `routes/` — TanStack Router file-based route components

```
routes/
├── __root.tsx         # Root layout, providers
├── index.tsx          # Home page
├── about.tsx          # About page
├── blog.index.tsx     # Blog listing page
└── blog.$slug.tsx     # Blog post page
```

Keep route files focused on routing concerns (loader, head, params) and composition — delegate complex logic to modules.

#### `app/styles/`

Global stylesheet (`styles.css`) — Tailwind imports and CSS custom properties. Imported once in `routes/__root.tsx`.

### `modules/`

Self-contained modules for distinct business concerns. Each module owns its components, hooks, state, and constants.

```
modules/
└── <module-name>/
    ├── components/
    ├── hooks/
    ├── <module-name>.store.ts   # Zustand (client/UI state)
    └── <module-name>.constants.ts
```

A module should not import from another module. Shared code belongs in `shared/`.

### `shared/`

Infrastructure and utilities used across 2+ modules or routes.

| Folder | Purpose |
|---|---|
| `ui/widgets/` | Composed UI blocks (Header, Footer) — reused across routes, may import from `shared/` |
| `ui/primitives/` | Generic, framework-agnostic UI components (shadcn/ui, icons) — no app knowledge |
| `ui/app/` | App-aware shared UI — knows about routes, errors, or app context |
| `lib/` | App config and third-party setup (site metadata, query client) |
| `api/` | API clients and DTOs, organized by domain |
| `queries/` | React Query queries and mutations (server state source of truth) |
| `hooks/` | Cross-module React hooks |

### `domain/`

Pure business logic — validators, calculations, type guards — with no framework dependencies.

```
domain/
└── <domain-name>/
    └── validators.ts
```

## Dependency Rules

```
app → modules → shared
                  ↑
domain ───────────┘ (independent, no outward deps)
```

- `app/` imports from modules and shared
- Modules import from shared, not from other modules
- `shared/ui/widgets/` imports from shared only
- Domain has no imports from other layers

## State Management

| Concern | Tool | Location |
|---|---|---|
| Server data | React Query | `shared/queries/` |
| Client / UI state | Zustand | `modules/<name>/<name>.store.ts` |

## Path Aliases

The `#/` alias (configured in `package.json` `imports` and `tsconfig.json`) maps to `src/`:

```ts
import { cn } from '#/shared/lib/utils'
import { ThemeToggle } from '#/modules/theme'
import Header from '#/shared/ui/widgets/header'
```
